# Quality Assurance Checklist

## Must-Pass Criteria

- ✓ Is 16:9 horizontal format.
- ✓ Background is clean white.
- ✓ Contains The Worker character.
- ✓ The Worker performs core action (not just decoration).
- ✓ Doesn't copy prior example compositions; new metaphor for current content.
- ✓ Composition feels strange, creative, engaging.
- ✓ Clean and simple; main subject ≤60% of canvas.
- ✓ One image, one core structure.
- ✓ Handwritten labels sparse, short, legible.
- ✓ Orange used only for primary flow or arrows.
- ✓ Red used only for warnings, problems, alerts, or results.
- ✓ Blue used only for secondary notes, feedback, or system state.

## Failure Signals (Regenerate or Edit)

- ❌ Top-left title like "Common Pitfalls / Workflow / System Architecture / Roadmap."
- ❌ The Worker looks like a cute mascot, emoji, or cartoon character.
- ❌ Composition feels like PPT, course slide, or formal flowchart.
- ❌ Too many elements, arrows, or nodes; feels crowded.
- ❌ Text becomes long explanation rather than sparse labels.
- ❌ Background has paper texture, shadows, gradients, beige tones, or noise.
- ❌ Real UI screenshots or sci-fi interface aesthetics.
- ❌ Text has serious typos or poor legibility.
- ❌ Composition is rigid and lacks absurd metaphor.
- ❌ Composition closely resembles prior examples in assets/examples/.

## Iteration Methods

| Problem | Solution |
|---------|----------|
| Too generic | Make The Worker the action centerpiece; add strange-but-logical metaphor. |
| Too crowded | Delete nodes; keep one action + 3–5 short labels. |
| Too cute | Emphasize deadpan, blank serious expression, "not cute," "not mascot." |
| Too much like PPT | Remove titles, borders, grids, excessive arrows; go sketch-scene instead. |
| Copies prior examples | Keep core idea; swap out objects and The Worker's action. |
| Text errors | Try local edit first; if many errors, regenerate with fewer labels. |

## Delivery Standard

Quality image should feel "strange at first glance," then readable in ~1 second.

If first impression is "instructional tutorial slide" rather than "weird whiteboard sketch," it fails.

# Image Generation Template

Generate each image separately. Replace variables from content; never combine multiple concepts.

```
Generate one standalone 16:9 horizontal sketch-style illustration.

Visual DNA:
Pure white background. Minimalist black hand-drawn line art. Slightly wobbly pen lines. Lots of empty white space. Sparse red/orange/blue handwritten annotations. Clean absurd product-sketch feeling. No gradients, no shadows, no paper texture, no complex background, no commercial vector style, no PPT infographic look, no cute mascot poster, no children's illustration, no realistic UI.

Recurring character required:
A solid-black minimalist creature with white dot eyes, thin legs, blank serious deadpan expression, slightly uneven hand-drawn body. Call it "The Worker." The Worker must perform the core conceptual action, not decorate the scene. Make it serious, deadpan, slightly bizarre, never cute.

Theme:
{Illustration topic and concept}

Structure type:
{One of: Workflow / System Component / Before-After / State Progression / Conceptual Metaphor / Method Hierarchy / Route/Path / Comic Frames}

Core idea:
{The one core insight this image conveys}

Composition:
{Specific scene: where is The Worker, what is it doing, what are main objects, how does information flow}

Suggested elements:
{element1} / {element2} / {element3} / {element4}

Handwritten labels/annotations:
{label1} / {label2} / {label3} / {label4} / {optional label5}

Color use:
Black for main line art and The Worker. Orange for primary flow, paths, arrows. Red only for key warnings, problems, or results. Blue only for secondary notes, feedback, or system state.

Constraints:
One image explains only one core structure. Keep main subject around 40–60% of canvas. Preserve at least 35% blank white space. Use at most 5–8 short handwritten labels. Do not write a title in the top-left corner. Do not write the structure type on the image. Do not make it a formal diagram, course slide, or dense explainer. Do not copy prior examples or reuse known compositions unless explicitly requested; invent a fresh visual metaphor for this specific content. Should be clear but not instructional, engaging but not childish, strange but clean.
```

## Image Editing Prompts

### Remove top-left title:

```
Edit the provided image. Remove only the handwritten title "{text-to-remove}" and its underline from the top-left corner. Fill that area with the same clean white background, matching surrounding blank space. Preserve everything else exactly: characters, labels, paths, line style, composition, aspect ratio, quality. Do not add new text or objects.
```

### Strengthen absurdity and Worker involvement:

```
Regenerate this illustration with the same core meaning and layout, but make The Worker more central to the conceptual action. The Worker should be doing the strange work that explains the idea, not standing beside the diagram. Keep it clean, sparse, hand-drawn, and not cute.
```

### Simplify and reduce text:

```
Regenerate with the same composition and idea, but reduce handwritten labels to at most 4. Remove text that restates the concept and keep only critical short labels. Make The Worker more prominent in the core action.
```

# The Worker Character IP

## Character Definition

"The Worker" is the recurring visual character in all illustrations—not a mascot or sticker, but a serious participant in the system's operation doing absurd work.

## Appearance

- Solid black minimalist creature.
- White circular dot eyes.
- Thin legs, sometimes thin arms.
- Body can be cylindrical, rounded, rectangular, funnel-shaped, shadow-like, or irregular.
- Slightly uneven outline with hand-drawn feel.
- Expression: blank, deadpan, calm, serious.

## Personality

- Very serious, but doing something strange.
- Like a quiet system operator or technician.
- Dry humor, never cutesy.
- A bit clumsy, but not incompetent.
- Like an actual crew member in a whiteboard sketch doing real work.

## Common Roles

Place the Worker in the core action:

- Moving/carrying materials.
- Pulling lines to connect information sources.
- Stuck at a bottleneck.
- Operating a decision lever inside a machine.
- Transforming into a filter or funnel.
- Separating or sorting elements.
- Stamping or approving a document.
- Guiding a connection path.
- Holding up a warning sign at a pitfall.
- Reaching out but not catching something.
- Beside the action: building, bridging, opening doors, sorting, recording.

## Taboos

- ❌ Don't make The Worker an overly cute mascot.
- ❌ Don't render as a children's cartoon character.
- ❌ Don't add complex clothing, emoji-like expressions, shiny eyes.
- ❌ Don't leave The Worker standing in a corner just watching.
- ❌ Don't let The Worker steal focus from the core structure.
- ❌ Don't make it too commercial, too round, too polished.

## Test Standard

If you remove The Worker and the core metaphor still works completely, The Worker is too decorative. Rewrite the prompt so The Worker performs the essential action.

# Composition Patterns & Metaphor Generation

## Basic Structure Types

Pick one type per image; don't mix too many.

### Workflow / Process

**Best for:** input → processing → output; content production; automation chains; system operations.

**How:** left=input, center=The Worker or processor, right=output, orange arrow shows main flow.

### System Component

**Best for:** data sources, filters, storage, renderers, parts of an agent system.

**How:** 3–5 core modules only; The Worker participates in one key action.

### Before-After Contrast

**Best for:** chaos/order, manual/automated, scattered/unified, stressed/calm.

**How:** left=chaotic state, right=resolved state, orange arrow between, character can be more exaggerated.

### State/Status Progression

**Best for:** user frustration, creator state, too many tools, information overload, stuck→running.

**How:** 2–4 small states, each with a short label.

### Conceptual Metaphor

**Best for:** content factory, information vault, mental black box, workflow engine, automated report.

**How:** one strange machine or creature; few inputs, one output, memorable.

### Method Hierarchy

**Best for:** methodologies, system layers, capability stacks, conceptual levels.

**How:** stacked boxes (not formal pyramids); The Worker beside them building or moving.

### Route / Path / Journey

**Best for:** idea-to-launch, user journey, content path, learning route.

**How:** one curved path, few waypoints, The Worker guiding or walking it.

### Comic Strip / Sequential Frames

**Best for:** failure→success, real process, complaints, before-after changes.

**How:** 2–4 small panels, each shows one action.

## Original Metaphor Generation

Invent a fresh metaphor from the current content every time. Don't recycle.

### Three-Step Process

1. **Convert abstract concept to physical action:** stuck, leaked, weighted, filtered, settled, fermented, gated, folded, unpacked, looped back.
2. **Convert system structure to low-tech object:** broken machine, cardboard box, drawer, pipe, mailbox, strange gauge, scale, well, ladder, odd workstation.
3. **Give The Worker the core action:** not standing beside, but stuck in the machine, pulling the wrong lever, guarding the gate, hauling, repairing, weighing, propping ladder, recording, stuffing things into a strange device.

### Object Pool (Use 1–2 per image)

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, coil, gate, turntable, black box, hole puncher, press, clothesline, strange workstation.

### Worker Action Pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, take apart, mark, recycle.

**Action must serve core idea—strangeness for its own sake is lazy.**

## Anti-Patterns (Don't Copy)

Don't copy these known compositions unless user explicitly requests it:

- Conveyor belt with two break points.
- The Worker pulling a decision lever inside a content machine.
- The Worker transformed into a filter separating flow/trust/conversion.
- The Worker cutting apart a metaphorical fish.
- The Worker guiding a connection path.
- The Worker pulling three information sources.
- Three Workers with megaphone/bridge/door.
- The Worker stamping a phrase into a toolbox.
- The Worker holding a sign at a pitfall path.

**For similar themes, invent new metaphors.** Example: "connection path" doesn't always need a route—The Worker could tape content tail to a doorknob. "Multi-use from one asset" doesn't need a fish—The Worker could press a paper ball into different shapes.

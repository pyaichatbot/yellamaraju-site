# GH-600 Certification Tutorial — Illustration Prompts

Eight concept-illustration prompts for GitHub Agentic AI Developer (GH-600) certification tutorial. Each prompt generates one 16:9 horizontal sketch-style illustration.

**Usage:** Copy each prompt section below. Paste into your image generator (DALL-E 3, Midjourney, or similar). Generate images sequentially.
